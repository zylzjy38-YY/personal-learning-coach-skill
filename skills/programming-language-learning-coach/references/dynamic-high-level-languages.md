# 动态高层语言路线

覆盖 Python、JavaScript。共同主线是动态类型与高层抽象，但对象模型、运行时和异步行为必须分别教学。

## Python

Python 为第一顺位语言。重点建立：

- 对象、名称绑定、身份、相等与类型；
- 可变对象、不可变对象、别名、浅复制和深复制；
- 作用域、闭包、函数对象、默认参数和参数传递；
- 列表、字典、集合及其语言层面的使用边界；
- 迭代协议、迭代器、生成器和上下文管理器；
- 异常产生、传播、捕获和清理；
- 模块、包、虚拟环境、`pyproject` 和依赖；
- 类型提示的用途与局限。

经典故障包括 `TypeError`、`AttributeError`、可变默认参数、作用域错误、循环导入和异常链。使用 PyCharm 的 Debugger、Frames、Watches、异常断点和测试运行器阅读 traceback 并定位根因。

Python 课程不默认加载 NumPy、pandas、机器学习或 Web 框架；这些只能按第五阶段项目需要引入。

## JavaScript

JavaScript 为扩展支持语言。默认以 Node.js 运行环境学习语言核心，避免一开始把 DOM 或前端框架混入语言语义。

重点建立：

- 基本值、对象、相等和隐式类型转换；
- 词法作用域、闭包、变量声明和提升；
- 对象、原型、类语法和 `this` 绑定；
- 数组与对象操作、迭代和模块；
- 事件循环、任务队列、Promise 和 `async`/`await`；
- 同步错误、异步错误和 Promise rejection 的传播；
- Node.js 项目、npm、测试、日志和配置。

经典故障包括 `TypeError`、读取 `undefined` 属性、错误的 `this`、未处理的 Promise rejection 和异步时序错误。使用 WebStorm、Node.js Debugger、异步调用栈和测试运行器。

## 教学边界

- 动态类型不等于没有类型规则；必须解释运行时对象、转换和错误产生条件。
- 高层语法不能遮蔽状态变化。对可变性、闭包和异步流程使用具体输入手动追踪。
- Python 与 JavaScript 的相似语法不能作为语义相同的证据。

适合的最终项目包括文件持久化的自动化工具、数据整理程序、CLI 或小型本地服务；项目难度不能主要依赖框架魔法。
