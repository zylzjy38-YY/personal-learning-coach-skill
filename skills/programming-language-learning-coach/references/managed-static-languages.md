# 静态托管语言路线

覆盖 Java、C#。共同主线是静态类型、对象协作和托管运行时，但具体平台规则分别教学。

## Java

Java 为第二顺位语言。重点建立：

- 编译、字节码和 JVM 运行的基本关系；
- 基本类型与引用类型、参数传递和对象生命周期；
- 类、封装、组合、继承、接口和多态的适用边界；
- 泛型、集合、迭代和对象相等性与哈希；
- 空值、异常产生与传播、受检与非受检异常；
- 垃圾回收能管理的内存与仍需显式关闭的资源；
- 包、模块、Maven 或 Gradle、测试、日志和配置。

经典故障包括 `NullPointerException`、`ClassCastException`、集合修改错误、错误的 `equals`/`hashCode`、异常吞掉和资源未关闭。使用 IntelliJ IDEA 的 Debugger、Call Stack、Watches 和测试运行器定位根因。

## C#

C# 为扩展支持语言。重点建立：

- 值类型、引用类型、可空性和参数传递；
- 类、接口、泛型、委托与事件；
- 集合、LINQ 的延迟执行和对象相等性；
- 异常、垃圾回收与 `IDisposable`；
- `async`/`await`、任务和异步异常；
- .NET 项目、依赖、测试、日志和配置。

经典故障包括 `NullReferenceException`、无效转换、集合修改、资源未释放和异步异常遗漏。使用 Rider 的 Debugger、异步调用栈和测试工具。

## 教学边界

- 不把面向对象术语清单当作课程。每个抽象必须由真实协作问题引出，并比较组合、接口和继承的代价。
- 不把垃圾回收说成“无需管理资源”；文件、连接和其他外部资源仍需明确生命周期。
- Spring、ASP.NET 等框架只在第五阶段后按项目需要引入，不能替代对象模型、异常和依赖的基础理解。

适合的最终项目包括带持久化、分层结构、测试和日志的控制台应用或小型本地服务。
