# 计算机实践、环境与网安迁移

## 实践证据

重要单元原则上取得以下至少三类证据；若某一类与知识点不自然，选择等价证据并说明理由。每个章节必须有适合的实践，但不为每个微小概念强行做实验。

1. 口头或文字解释；
2. 手工推演、计算或状态追踪；
3. 代码、实验、抓包、命令行、模拟或工具观察；
4. 陌生案例分析与迁移。

实践流程：说明目标和安全边界；检查最小环境；让用户先预测；执行；收集代码、输出、截图、抓包或测量；对照预测分析；测试边界；记录证据。程序能运行或出现预期截图不自动等于理解，用户还需解释关键状态、原因、条件和失败方式。

环境或工具失败时区分安装、权限、命令、代码和理论问题。不能取得有效证据时明确验证缺口，提供与当前目标等价的模拟或离线替代，不虚报通过。

## 渐进环境路线

使用 Windows 作为日常系统，按知识需求引入工具：

1. 第一阶段：Windows、自包含代码、本地或在线模拟器；
2. 第二阶段：WSL、基础命令行、编译器、Wireshark 和数据库；
3. 第三阶段：Linux 系统观察、网络实验和隔离虚拟机；
4. 第四至第五阶段：教学操作系统、复杂网络环境、性能实验和授权安全靶场。

不在课程开始时一次安装全部环境。每次安装都说明本节为何需要、版本或权限前提、成功检查和卸载或替代方案。可能改变系统网络、虚拟化或安全配置时先说明影响，并仅执行用户授权范围内的操作。

## 数据结构与算法实践

- 先形成朴素解法，再识别瓶颈；
- 用具体输入手动追踪结构、关键变量和不变量；
- 实现核心数据结构或算法，并覆盖空输入、极值、重复值、退化结构和错误输入；
- 检查正确性、终止和时间空间复杂度；
- 比较实现、调试故意带错的代码、测量性能；
- 用表面不同的任务验证迁移。

网安关联限于自然位置，例如字符串匹配、图搜索、哈希、资源耗尽、算法复杂度攻击和边界条件。不能用安全背景替代数据结构本体。

## 计算机组成原理实践

- 二进制、补码、位运算和数据表示实验；
- 简单汇编与指令逐步执行；
- 数据通路、控制信号、流水线或中断模拟；
- 缓存命中、替换和局部性测量；
- 高级语言、汇编和机器指令之间的对应分析。

网安关联包括特权级、内存保护、指令执行、缓存和侧信道产生的基础条件。第一阶段只建立联系，高阶段再分析限制与防护。

## 操作系统实践

- 使用系统工具观察进程、线程、文件、内存和权限；
- 编写进程、线程、锁、管道、文件和系统调用的小程序；
- 复现并分析竞争、死锁、调度和页面置换；
- 阅读教学操作系统的局部代码，先预测调用关系再验证；
- 高阶段完成教学操作系统或等价实验。

网安关联包括隔离、权限、系统调用、竞态、内存安全、访问控制和审计。实验在本机或隔离环境进行。

## 计算机网络实践

- 使用抓包工具观察协议字段和事件顺序；
- 编写简单客户端、服务器或协议模拟器；
- 预测握手、重传、窗口、路由或应用层交互，再用抓包验证；
- 在隔离环境模拟延迟、丢包、带宽和故障；
- 根据日志、抓包和配置定位网络现象。

网安关联包括 ARP、DNS、TCP、TLS、防火墙和异常流量的原理与防护。区分协议规范、常见实现和本次环境观察。攻击性现象只在授权靶场、隔离网络或离线数据中演示。

## 数据库实践

- 实际执行 SQL 并检查结果与边界；
- 从需求设计模式、主键、外键、约束和索引；
- 制造异常数据验证完整性规则；
- 观察事务、锁、隔离级别和并发现象；
- 阅读执行计划，测量索引和查询改写的影响；
- 完成小型综合数据库设计、测试和性能分析。

网安关联包括 SQL 注入形成条件、参数化查询、最小权限、审计、备份恢复和数据泄露风险。不能只展示攻击字符串而省略输入边界、执行语义与防护验证。

## 安全边界

- 任何外部目标都需要明确授权；缺少授权时不得扫描、利用、绕过控制或干扰服务。
- 将学习任务改为本机、隔离虚拟机、授权靶场、模拟器或离线抓包。
- 说明安全实验可能影响的进程、端口、网络和数据，保留恢复路径。
- 不因用户是网络空间安全专业就默认扩大操作授权。
- 安全内容用于深化核心课机制；当它挤占当前课程目标时，明确返回主线。
