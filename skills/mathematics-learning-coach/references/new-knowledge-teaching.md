# 数学新知识讲解规则

## 确定目标与前置知识

1. 说明本节要解决的问题、学习后的可观察目标及其与当前章节的关系。
2. 列出本次讲解实际使用的必要前置知识，不无限追溯，也不建立脱离教材顺序的固定假设。
3. 依据当前会话、学习进度和独立作答证据，把前置知识标为“已验证掌握”“未知”或“未掌握”。
4. 对已验证掌握的前置知识，在首次使用时仍说明名称、成立条件和本次作用。
5. 对状态未知的前置知识，先问一个聚焦问题或给一道最小诊断题；不要默认会，也不要机械重讲全部先修内容。
6. 对未掌握的前置知识暂停主线并插入小型先修课。学习者主动指出“这个没学过”时同样处理。

## 插入小型先修课

1. 只补到当前主知识点真正需要的深度，并说明以后在哪个章节系统学习。
2. 依次讲清直观动机、准确概念或定理、成立条件、简单例子和当前用途。
3. 用 1–3 道基础检查题确认最低必要掌握程度；未通过时继续补最小缺口。
4. 通过后明确恢复原知识点，并指出这项前置知识在当前推导或证明中承担的作用。

## 由浅入深讲解

1. 从学习者已知的现象、问题、图形、例子或旧知识提出动机。
2. 用日常语言给出第一层直观认识，同时标明直观说法的边界。
3. 给出准确的定义、符号、对象和成立条件，逐项解释新符号。
4. 按 [mathematics.md](mathematics.md) 推导核心结论或完成证明，明确每一步依据。
5. 说明如何从题目中识别该知识、怎样使用、何时不能使用及常见混淆。
6. 用一个最小例子验证核心关系，再根据难度安排题组或单题练习。
7. 结束前检查本节是否回答“是什么、为什么、如何得到、何时能用、何时不能用、如何识别、如何验证”。只覆盖当前阶段所需内容。

## 处理超出当前阶段的内容

- 核心结论必须在已确认的基础上讲清，不能用更高级且未学的结论制造循环解释。
- 辅助结论的完整证明若明显超出当前阶段，标记为“暂时引用”，说明依赖内容、当前可使用范围和将来补全位置。
- 学习者追问某一步时，从第一处不理解或未经证明的位置拆解，不机械重复整段讲解。
- 发现先前错误地默认了前置知识时，明确承认遗漏，撤回受影响的推导并从缺失前提重建。

## 安排练习

- 单一知识点的基础识别、直接代入或简单运算，一次给 3 道题。
- 覆盖多个基础类型或区分相近概念时，一次给 4–6 道题。
- 新方法、综合推理、长计算、开放证明或需要观察中间步骤时，一次只给一道题。
- 题目覆盖定义、条件、计算或证明中的真实差异，不以改数字制造虚假多样性。
- 批改完当前题组或单题后再安排下一项任务，不在同一轮堆叠多组待办。
