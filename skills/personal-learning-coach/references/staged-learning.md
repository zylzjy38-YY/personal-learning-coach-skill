# 五阶段学习与晋级测试

## 基本原则

- 阶段表示可观察能力，不表示看完多少章节或学习多少小时。
- 针对每个新学科先建立知识覆盖图，再把内容分配到五个阶段。
- 允许不同知识模块暂时处于不同阶段，但课程记录必须给出一个当前主阶段和具体短板。
- 只用独立作答、解释、验证和迁移表现作为晋级证据，不以“听懂了”“看熟了”作为证据。

## 五个阶段

### 第一阶段：概念入门

目标：掌握课本范围内的基本概念、符号、对象、条件和最基础操作，能用自己的话解释“是什么、为什么需要、何时可用”。

教学重点：

- 建立完整概念图，补齐先修知识。
- 用几何、图示、运行过程或具体例子解释抽象定义。
- 练习单一知识点的基础题，避免过早堆叠技巧。
- 纠正术语混淆和对定义条件的遗漏。

晋级证据：能独立解释核心概念，完成课本基础题，准确识别基本对象和条件，不再依赖逐步模仿。

### 第二阶段：标准熟练

目标：熟练使用课程中的标准方法，能根据题目特征选择常用方法，并稳定完成典型题。

教学重点：

- 覆盖所有基础方法及其适用条件。
- 训练设式、计算、代码实现或证明的完整性。
- 比较相近方法，形成基本选择规则。
- 通过变式消除只会照模板的问题。

晋级证据：标准题正确率和完整性稳定，能说明方法选择依据，能发现并修正常见错误。

### 第三阶段：深化迁移

目标：理解方法背后的结构，掌握自然的技巧与联系，能处理非标准变式并在不同表示之间迁移。

教学重点：

- 推导重要公式和方法，不只记结论。
- 组合两种以上基础方法，比较效率与限制。
- 引入替换、构造、对称、不变量、反例等结构性技巧。
- 训练一题多解、逆向分析和陌生表述下的识别。

晋级证据：面对未见过的变式能独立拆解，能从条件识别结构，并能解释技巧为什么成立、何时失效。

### 第四阶段：高阶综合

目标：稳定解决高难度课程考试和高水平大学期末题，能在时间压力下处理多知识点、长链条问题。

教学重点：

- 综合多个章节和先修知识。
- 训练复杂条件解析、方法取舍、计算控制和验证。
- 使用高质量期末题、选拔题或同等难度原创题。
- 进行限时训练和系统错因复盘。

晋级证据：在未提示、限时条件下稳定完成高难综合题；关键步骤严谨，失误率可控，遇到卡点能自行换角度。

### 第五阶段：竞赛或专业级表现

目标：针对明确目标形成竞赛或专业任务能力。数学竞赛方向应达到相应赛制下的真题处理、策略分配、严谨证明、速度和稳定性要求。

教学重点：

- 使用真实赛制、历年题型和高质量模拟题校准，不泛称“竞赛级”。
- 训练陌生结构识别、跨章节组合、关键突破和解答表达。
- 进行完整限时模拟，分析得分策略与时间分配。
- 检查能力是否能跨题迁移，而不是只会做练过的题型。

达标证据：至少两次不同卷或不同综合题组的独立限时表现达到预设线，且没有持续性的基础漏洞。一次小测或偶然做出一道难题不足以证明竞赛水平。

## 重积分路线校准示例

该示例用于理解阶段尺度，实际课程应根据教材、考试范围和最新目标赛制细化。

- 第一阶段：理解二重与三重积分的来源、几何和物理意义；会描述积分区域；掌握直角、极、柱、球坐标的基本概念与体积元。
- 第二阶段：熟练确定积分限、交换积分次序、选择常用坐标系、使用基本对称性，完成体积、质量、质心等标准应用。
- 第三阶段：掌握非平凡变量代换与雅可比、复杂区域分段、交换对称与奇偶性的组合、参数化区域及多方法比较，理解方法的适用边界。
- 第四阶段：独立完成高水平大学期末和选拔难题，包括多曲面约束、跨章节综合、长计算链与限时验证。
- 第五阶段：按 CMC 目标组别和赛制，用真题或同等质量题组训练陌生构造、综合技巧、严谨书写和时间分配，以多次模拟结果判断竞赛准备度。

## 晋级测试蓝图

### 设计测试

1. 列出当前阶段全部核心模块和能力目标。
2. 建立“模块 -> 题目或小问”覆盖表，确保每个核心模块至少被一个有效任务检验。
3. 合并可在一道综合题中自然检验的多个知识点；不要为追求字面上的“全部出题”制造几十道重复小题。
4. 使用学习者未见过但难度与训练一致的题目，避免直接复用刚讲过的例题。
5. 通常设计 5-8 道题或等量小问；阶段越高，题目数量可以减少但综合性和时限要求提高。
6. 测试前完整说明范围、时限、是否允许资料、评分标准。测试中默认不给提示。

### 评分结构

按 100 分记录，并根据学科调整题型但不降低标准：

- 核心概念与条件：20 分
- 标准方法与执行正确性：30 分
- 方法选择与理由：15 分
- 综合、变式与迁移：25 分
- 验证、表达与错误诊断：10 分

### 晋级条件

同时满足：

- 总分至少 80 分；
- 每个核心模块至少达到 70%；
- 不存在未纠正的基础概念错误；
- 至少一道未见迁移题独立完成；
- 关键题未依赖超过一级提示。使用实质性提示完成的题只能记为辅助表现，必须换题复测。

根据目标可提高门槛，但不得在测试后为了让学习者晋级而临时降低标准。

### 未通过时

1. 按概念、读题、方法选择、推导或算法、计算或实现、验证六类建立缺口表。
2. 只重教真正薄弱的前提；为每个缺口安排少量针对练习和一个变式。
3. 间隔后复测薄弱模块，并加入一道综合锚定题检查是否能重新连接全阶段知识。
4. 若多个核心模块均低于门槛，重新进行完整阶段测试；若仅一个局部缺口，进行局部复测即可。
5. 记录原测试、补弱证据和复测结果，不删除失败记录。

## 初始定级

新课程开始时不要默认从第一阶段或按学习者自评定级。使用短诊断从第一阶段核心概念开始，逐步加入第二、第三阶段任务；出现稳定断点后，把主阶段定在能够独立完成的最高阶段，并从第一个未掌握模块开始教学。
